# Flask Image Upload App

A Flask web application for uploading and previewing images.

## Features
- Upload images
- Image preview
- File validation
- Static file serving

## Technologies Used
- Python
- Flask
- HTML

## Installation

pip install flask

## Run

python app.py

Open browser:
http://127.0.0.1:5000

## Supported Formats
- PNG
- JPG
- JPEG
- GIF

## Purpose
focuses on image handling and static file serving in Flask.
